# Aethel

Офлайн-трекер для **Genshin Impact**, **Honkai: Star Rail** и **Zenless Zone Zero**.
Без интернета, без регистрации — все данные хранятся на устройстве. Автор: **RonovaDev**.

## Функции

- **Главная** — сводка по выбранной игре: поручения, энергия (смола / энергия / заряд), подписка (Полая луна и аналоги), гарант, ближайшие события.
- **Крутки** — баннеры каждой игры, счётчик 5★/4★, мягкий и жёсткий гарант, 50/50 и гарантия, средняя крутка, процент выигрыша, история, планировщик ресурсов.
- **Поручения** — ежедневные, еженедельные, периодические (1 и 16 числа, раз в месяц), свои поручения, своё время обновления.
- **События** — таймеры с датой/временем, повтором и напоминанием заранее.
- **Профиль** — локальный профиль, UID/уровень, основная игра (стартовая), экспорт/импорт базы, CSV, кнопка **i** «О программе».
- **Настройки** — светлая/тёмная/системная тема, AMOLED, палитры (динамическая, Aethel, Сакура, Океан, Мята), уведомления, настройки для каждой игры.

## Заметки

- Гарант считается по введённым вручную данным; пороги и правила 50/50 заданы в `data/GameCatalog.kt`.
- Время обновления поручений каждый пользователь задаёт сам (по своим часам) — в онбординге, на вкладке «Поручения» или в настройках.
- Для точных напоминаний на Android 12+ разрешите «Точные будильники» (кнопка в настройках).
- Неофициальное приложение, не связано с HoYoverse.
